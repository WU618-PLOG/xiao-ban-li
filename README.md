# 小板栗 · Little Chestnut

像素风日历待办应用：每天完成小目标，解锁隐藏任务和陪伴伙伴。

**在线使用**：https://wu618-plog.github.io/xiao-ban-li/

## 功能

- 日历视图 + 每日待办清单，支持任务分组
- 倒计时横幅与重要日期提醒
- 专注模式：沉浸式计时，帮你快速进入状态
- 陪伴伙伴：坚持完成任务，解锁隐藏伙伴
- 白天 / 夜晚双主题，随心情切换
- 离线可用：断网也能打开（PWA 离线缓存）
- 手机安装：添加到主屏幕后，像原生 App 一样使用

## 安装到手机

- iPhone / iPad：用 Safari 打开上面的网址 → 点「分享」→「添加到主屏幕」
- Android：用 Chrome 打开网址 → 菜单 →「安装应用 / 添加到主屏幕」

## 数据隐私

所有数据都保存在你自己的浏览器本地（localStorage），不会上传到任何服务器。

## 技术

纯前端实现（HTML / CSS / JavaScript），零依赖，托管于 GitHub Pages。
